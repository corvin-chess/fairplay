<p align="center"><img src="https://readme-typing-svg.demolab.com?font=IBM+Plex+Mono&weight=700&size=18&color=8FA3D9&center=true&vCenter=true&width=420&height=40&duration=1&pause=1000000&letterSpacing=6px&lines=OVERVIEW" alt="Overview" /></p>

Planned Rust library and reviewer CLI for Corvin fair play. Intended surfaces: public feature extraction and statistical tests, a scoring API consumed by [server](https://github.com/corvin-chess/server), and review tooling. Depends on [chess-core](https://github.com/corvin-chess/chess-core) for rules context; optional use of [engine](https://github.com/corvin-chess/engine) for analysis features. Public code may describe detection mechanisms. Never commit thresholds, weights, trained detection models, or review heuristics; those load from private configuration at runtime only (ADR-014). No fair play source is in this repository yet.
